# 记不住的英语单词

## 1. 第一阶段

    primitive path          原始路径
    property            财产
    rigid body          刚体
    argparser           参数解析（不是单词）
    Rest everything follows         其余内容如下
    spawn a green cone with colliders and rigid body           生成一个带有碰撞体和刚体的绿色圆锥体
    rigid           刚性
    props           道具
    spawn a blue cuboid with deformable body        生成一个可变形的蓝色长方体
    deformable          可变形的
    spawn a usd file of a table into the scene      在场景中生成一张表的usd文件
    Initialize the simulation context           初始化模拟上下文
    intensity           强度
    entity          实体
    sample a random position on a cylinder around the origins       在圆柱体上围绕原点随机取样
    spawn           生成
    utils           工具
    Define simulation stepping          定义模拟步长
    articulation                多刚体关节系统
    InteractiveScene            交互式场景
    SimulationContext           模拟上下文
    Omniverse           全宇宙（这个其实就是人家名字而已）
    Cuboid          长方体
    nodal_kinematic_target          节点运动目标
    enumerate           列举
    quaternion          四元数
    instance            实例
    vertices            顶点
    slider          滑块
    cart            车
    intensity           强度
    inference mode          推理模式
    sample random actions       随机行为样本
    truncated           截断
    locomotion          运动
    manipulation            操纵
    Sequence            序列
    render_interval         渲染间隔
    render mode         渲染模式
    Standard deviation          标准偏差
    Instantaneous reward            瞬时奖励
    KL Divergence           散度
